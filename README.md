# 🔐 Authentication Login API (Express + Cookies)

This is a simple **Authentication API** built using **Express.js** and **cookie-based authentication**.
It demonstrates how login, protected routes, and logout work using cookies.

---

## 🚀 Features

*  User Login with credentials
*  Cookie-based Authentication
*  Protected Route (`/dashboard`)
*  Logout functionality (clear cookies)


---

## 📦 Tech Stack

* Node.js
* Express.js
* cookie-parser

---

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/vijayvasupalli/Authentication-loginAPI.git

# Navigate into project
cd express-js-tutorial

# Install dependencies
npm install
```

---

## ▶️ Run the Server

```bash
nodemon src/authentication.js
```
